Pro vývojáře

Funkční

npm, Bun, pip, Cargo, vcpkg, .NET Tool, PowerShell 7 / 5 – hledání, instalace, aktualizace a odinstalace v režimu Vývojář. Chybějící Node.js, Python, Rust, .NET SDK nebo PowerShell 7 nainstaluje Unibox přes WinGet.

Pro pokročilé a vývojáře

Režim Vývojář a příkazy ke zkopírování.

Přepněte do režimu „Vývojář“ a spravujte i knihovny a nástroje pro vývojáře – hledání, instalace, aktualizace i odinstalace přímo v Uniboxu. U každé aplikace najdete hotové příkazy pro WinGet, Chocolatey, Scoop a další – zkopírujete je jedním kliknutím. Sady balíčků exportujete jako skript PowerShellu.

  • npm, Bun, pip, Cargo, vcpkg, .NET Tool a PowerShell naostro
  • Chybějící Node.js, Python nebo Rust doinstaluje jedním kliknutím
  • Export a import profilů
PS> winget install --id Microsoft.VisualStudioCode -e
