  • If an operation fails due to permissions, Unibox retries it as administrator

Advanced uninstall

Uninstallers often leave settings, caches, shortcuts and registry keys behind. After an uninstall, Unibox finds them – in AppData, Program Files and ProgramData, the Start menu, on the desktop and in the Windows registry – and offers to delete them. Or it cleans them up right away and just lets you know.

With install monitoring, Unibox takes a disk and registry snapshot before and after an install. It remembers what the installer created and offers to remove all of it after an uninstall – even items it couldn’t find by name.

  • Files go to the Recycle Bin; registry keys are backed up before they’re deleted
  • Never deletes anything that belongs to another installed app
  • Closes the running app before the uninstall
  • Off by default – turn it on in Settings

Questions and answers

Frequently asked questions

Windows shows a SmartScreen warning when I run the installer. Is that okay?

The Unibox installer isn’t digitally signed yet, so Windows shows the “Windows protected your PC” dialog. Click More info and then Run anyway. A signed installer is on our roadmap.

What does “preview” mean?

Unibox is still in an early stage of development – the first public version 0.1.0 came out in October 2026 and updates have been arriving since (see What’s new). WinGet, Chocolatey, Scoop and developer package managers (npm, pip, Cargo and more) work for real – search, install, update and uninstall. You may run into the occasional bug.

Is Unibox free?

Yes. Unibox is open source under the MIT license – free, with no ads and no bundled extras.

Where does Unibox download apps from? Is it safe?

Only from the official repositories of package managers. Unibox downloads the installer and WinGet verifies its SHA-256 checksum before running it – if the file differs from the published one, the installation doesn’t happen.

Will Unibox show apps I installed before?

Yes. The installed apps overview includes programs installed outside WinGet, Microsoft Store apps and Steam games. You can update them, uninstall them or launch them with the Open button.

Do I need administrator rights?

Not to install Unibox – the EXE installer installs for the current user. If installing an app requires administrator rights, Unibox retries it and asks for them (UAC).

What’s the difference between the EXE and MSI installers?

The EXE is recommended for most people: it installs without administrator rights and offers English and Czech. The MSI is meant for deploying across a company.
