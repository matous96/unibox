For developers

Working

npm, Bun, pip, Cargo, vcpkg, .NET Tool, PowerShell 7 / 5 – search, install, update and uninstall in Developer mode. If Node.js, Python, Rust, the .NET SDK or PowerShell 7 is missing, HubGet installs it via WinGet.

For power users and developers

Developer mode and copy-ready commands.

Switch to “Developer” mode to manage libraries and developer tools too – search, install, update and uninstall right in HubGet. Every app comes with ready-made commands for WinGet, Chocolatey, Scoop and more – copy them in one click. Export bundles as a PowerShell script.

  • npm, Bun, pip, Cargo, vcpkg, .NET Tool and PowerShell for real
  • Installs a missing Node.js, Python or Rust in one click
  • An overview of terminal commands for every manager, with explanations
  • Profile export and import
